# 空間透鏡 · Space Lens

以 Rust 開發的 macOS 磁碟空間分析工具。提供繁體中文獨立視窗、資料夾容量清單、空間圖、類別篩選與批次整理。掃描資料留在本機，沒有帳號、遙測或上傳功能。

目前版本：**0.4.0**，本機預覽版。

## 功能

- 背景掃描資料夾，顯示掃描狀態並可取消。
- 可點選的空間圖、逐層瀏覽、檔名搜尋與容量升冪／降冪排序。
- 區分檔案邏輯大小與配置空間估計。
- 影片、圖片、音訊、文件、壓縮檔／安裝檔、應用程式、App 資料、快取／記錄及其他類別，可複選篩選。
- 勾選框、Command 點選、Shift 範圍選取與全選顯示項目。
- 在 Finder 顯示項目、移到垃圾桶，以及經明確確認的永久刪除。
- 刪除進度條、目前處理路徑、已用時間與成功／失敗明細。

## 操作

1. 按「選擇資料夾」，或使用下載項目、桌面等快捷入口。
2. 掃描完成後，單擊項目查看細節，雙擊資料夾進入；可切換「所有大型檔案」。
3. 在「容量排序」切換小到大或大到小。
4. 若要依類別清理，複選所需類別，再按「全選符合類別的檔案」。名稱搜尋也會限制此選取範圍。
5. 按下方的垃圾桶或永久刪除按鈕，確認完整路徑清單後執行。

選取**資料夾**會連同資料夾本身及其中所有內容一起移除；依類別選取的清單只包含**檔案**，保留父資料夾。切換資料夾、類別或搜尋條件會清除舊選取，改變排序則保留選取。

進度按「所選項目」計算，並非容量或子檔案數的百分比。單一資料夾全部處理完成後才前進；等待 NAS 回應時仍會持續計時。

## 刪除行為

- 移到垃圾桶不會自動清空垃圾桶。可從 Finder 的垃圾桶將項目拖回原位置。
- NAS 或外接磁碟可能沒有垃圾桶。失敗後可另外選擇「永久刪除失敗項目」，不會自動改成永久刪除。
- **永久刪除不經垃圾桶，無法從垃圾桶復原。**仍需磁碟與帳號的刪除權限；資料夾當下的所有內容都在操作範圍內，0 B 不代表可放心刪除。
- 操作前重新檢查 canonical path、裝置與 inode；阻擋掃描根目錄、系統目錄、個人主目錄及整個個人 Library。
- 永久刪除不跟隨資料夾內的符號連結，檢查到跨磁碟子目錄會拒絕。刪除失敗時可能已移除部分內容，會保留明細並重新掃描。
- 掃描及刪除不是檔案系統交易，仍存在檢查與操作之間的競態；不適合作為對抗惡意本機程序的安全邊界。

## 容量與分類限制

掃描包含隱藏檔，不跟隨符號連結、不跨越不同裝置；外接磁碟需另外選取。硬連結只計算第一次遇到的路徑。無法讀取、略過與取消情況會顯示，讀取錯誤明細最多保留 50 筆。

使用十進位 KB／MB／GB。配置空間取自檔案系統配置區塊，不包含磁碟中繼資料與快照的完整占用；APFS 共享區塊可能重複計算，數字不代表保證可釋放的容量。掃描期間檔案變動也可能影響統計。

類別根據副檔名與路徑推估，不代表執行中程序的用量，也不保證檔案由特定 App 建立。類別總計涵蓋目前資料夾，與名稱搜尋條件無關。

## 開發與打包

需要 macOS、Rust stable，以及 Apple Xcode 或 Command Line Tools。已在 Apple Silicon Mac 上建置與測試；尚未驗證 Intel 或其他 macOS 版本。

```sh
cargo run
cargo test --locked
cargo fmt --check
cargo clippy --all-targets --locked -- -D warnings
bash scripts/bundle.sh
open 'dist/空間透鏡.app'
```

若 Rust 未加入 PATH，可使用 `~/.cargo/bin/cargo`。打包腳本預設使用 `/Library/Developer/CommandLineTools`，可透過 `DEVELOPER_DIR` 覆寫；`CARGO_BIN` 可指定 Cargo 路徑。要另外輸出 App 而保留正在運作的舊版：

```sh
APP='dist/空間透鏡 0.4.0.app' bash scripts/bundle.sh
```

`Cargo.lock` 固定依賴版本。App 使用本機 ad-hoc 簽章，尚未完成 Developer ID 簽署與 Apple 公證。中文字型在執行時讀取 macOS 系統字型，不隨專案散布。

一般測試包含自建暫存檔的永久刪除驗證。需要實測 macOS 垃圾桶時，可明確執行以下測試；它只移動新建立的測試檔與資料夾：

```sh
cargo test --locked native_trash_smoke_test -- --ignored
```

## 專案結構

| 路徑 | 用途 |
| --- | --- |
| `src/main.rs` | egui／eframe 介面與互動 |
| `src/scan.rs` | 掃描、容量統計、刪除與進度 |
| `src/view.rs` | 分類、排序、多選與父子項目去重 |
| `scripts/bundle.sh` | 建立 macOS `.app` |
| `scripts/make-icon.py` | 產生幾何圖示 |
| `packaging/` | App metadata 與圖示 |

編譯暫存、打包產物、測試資料與本機驗證紀錄不納入 Git。
